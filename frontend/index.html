AI Security Agent & Threat Advisor

Real-time incident analysis, root cause explanations, and non-destructive defensive guidance

The AI Security Agent operates in an advisory capacity. It inspects flagged intrusion flows, explains why the traffic pattern triggered machine learning detection, analyzes protocol behaviors, and suggests recommended remediation steps without modifying local firewall rules or executing destructive actions.

Denial of Service (DoS) High

Floods target hosts with excessive packet rates or malformed requests to deplete network and CPU resources.

Key Features: high rate, sbytes, ct_srv_dst
Reconnaissance Medium

Scans network ports and host services (e.g. Nmap SYN sweeps) to discover vulnerable attack vectors.

Key Features: ct_dst_sport_ltm, synack, sttl
Exploits Critical

Targets known software vulnerabilities (CVEs) by delivering structured malicious payloads.

Key Features: sbytes, dmean, service
Fuzzers Medium

Submits semi-randomized data payloads to trigger unexpected buffer overflows or application faults.

Key Features: smean, sloss, tcprtt
Backdoors & Shellcode Critical

Establishes covert command-and-control channels or injects bytecode instructions for arbitrary code execution.

Key Features: sttl, ct_state_ttl, dbytes
Generic Attacks Medium

Cryptographic collision or protocol manipulation attacks that bypass standard security filters.

Key Features: ct_dst_src_ltm, rate, sloss
